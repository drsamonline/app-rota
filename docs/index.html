Blocked: Ravi is already on 06–14 that day. Two shifts for one person on one day is never a plan — it is a mistake, so the app will not save it.

Blocked vs warned

The difference is deliberate. A double-booking is a mistake; a long run is sometimes a decision the team has made. One stops the save, the other asks.

What it refuses

It will not quietly overwrite a shift, and it will not save a clash because you were in a hurry.
