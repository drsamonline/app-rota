Rota

Build the rota, catch the clashes, see the load per person, and print it. No pay is calculated.

Open Rota
Status Built and working offline: a grid of days × slots for a small team; clashes (two people on one slot) flagged and blocking the save; rest-day violations naming the person and the day the run broke the rule; gaps listed rather than hidden; the load per person so fairness is visible; swap requests refused when the shift is not yours, with both shifts shown; and a Markdown print whose row count equals the screen.
Release: Windows EXE, Android APK and Linux binary, built from this source in CI — app-latest.
Not built: sharing over a LAN. The app opens locally and says the others have not seen the change yet, rather than pretending a team agreed to something they never received.

What it does

  • Checks the rules, not just the gaps: consecutive days, two people on one slot, and empty slots.
  • Blocks saving a rota with a clash — two people on one slot is not a rota, it is a mistake.
  • Names the person and the day a rest-day run breaks the rule.
  • Shows the load per person, so fairness is visible rather than argued about.
  • Prints one row per person per day, and states the row count so it can be checked against the screen.

What it will not do

  • Calculate pay. There is no rate, no salary and no money field anywhere in it.
  • Hide a gap. An unfilled slot is accepted and listed.
  • Let you swap a shift you are not on. Refused, with both shifts shown.
  • Merge an unreadable rota into a live one. That would move shifts people have already planned around; it is quarantined and offered for export.
  • Claim the team has seen it. Every change is pending until others see it — which this version cannot do.
  • Use a key or a network. No fetch, no endpoint; CSP connect-src 'none'.

When things go wrong

CaseWhat happens
Bad inputA swap for a shift you are not on is refused with both shifts shown. A slot left empty is accepted and listed. A clash blocks the save.
No networkNothing changes. The app opens locally and says the others have not seen the change yet.
Storage full or unavailableThe change is not written and the app says so; it is never shown as agreed with the team.
Corrupt saved stateReported and quarantined, never merged into a live rota.

How to run it

  • Here: play/index.html, or install it from your browser's menu.
  • Offline file: open docs/play/index.html straight from disk.
  • Tests: node tests/self-tests.js — the spec's countable “done means” is asserted there.
